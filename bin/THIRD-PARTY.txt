Local extension append-v1 adds the append-pages guarded transaction command and
changes Sync retry exhaustion to return an error. Added files:
api/sync15/appendpages.go, api/sync15/appendpages_test.go,
shell/appendpages.go, shell/appendpages_test.go.
Append recovery requires nonempty verified mappings, including read-only CRDT
identity/order/redirect checks. CRDT content writes remain unsupported.
Modified upstream files: api/sync15/apictx.go and shell/shell.go.
Local extension auth-v1 prevents token refresh on non-401 errors, reuses valid
unexpired tokens, checks atomic token persistence, and releases the legacy
authentication mutex on errors. HTTP 429 immediately stops requests and stores
a credential-free cooldown beside RMAPI_CONFIG for at least one minute,
honoring longer Retry-After delays. Includes offline mocked-HTTP regression tests.
Additional changed upstream files: main.go, api/auth.go, api/sync15/tree.go,
config/config.go, transport/transport.go, auth/transport.go. Added tests and
transport/ratelimit.go are included in the corresponding source archive.
Local extension cache-v1 exposes the full document file-tree hash as the optional
contentHash field in JSON ls/find output. Changes: model/document.go,
api/sync15/blobdoc.go, shell/output.go; corresponding ContentHash tests included.

The helper is a separate command-line program. Guarded append was verified
against a disposable cloud document: same ID, appended pages, unchanged other
archive members, idempotent retry. The test document was archived afterward.
Pair it using ../scripts/pair-rmapi.ps1 before use.
Keep its authentication file outside any synchronized Obsidian vault.

texts are retained inside each original module archive. In particular UniPDF
